# 三处随机文字毛边规则

## 硬性数量

每篇完成拟人化的文章加入恰好 3 处有意文字毛边。少于三处不交付，多于三处要删除到三处。原文已有自然错别字或重复字时，先判断是否可计入；可计入的毛边不再重复新增。

## 随机选择

从下列三类候选中随机抽取三处，至少覆盖两类，且同一自然段最多一处：

1. **连续重复字或短词，权重 45%**：如「我我」「这个这个」「就就」「再再」。优先模拟口述回填，不重复专名或实义关键词。
2. **常见输入法错别字，权重 35%**：只选不改变句子核心意思的轻微错误，如「已经／以经」「时候／时侯」「觉得／觉的」。不要使用会产生另一种事实含义的替换。
3. **助词或连接位置的轻微同音混用，权重 20%**：只落在普通叙述中，例如非关键位置的「的／地／得」混用。无法确认不影响理解时，改选前两类。

随机不等于完全失控。先列出全部安全候选位置，再按权重选择类型和位置；候选不足时，优先使用重复字，不要制造危险错字。

## 绝对禁区

不得落在：

- 标题、导读标题、列表标签和小标题；
- 人名、公司名、产品名、型号、专业术语和功能名；
- 数字、时间、价格、数据、网址和链接文字；
- 正式引语、Slogan、用户确认的最终文案；
- Markdown 图片语法、图注、HTML 标签和属性；
- 免责声明、行动按钮、CTA 和关键结论；
- 任何可能改变事实、立场或操作步骤的位置。

## 内部复核

交付前在内部记录三项：所在段落、原写法、毛边写法。确认：

- 总数恰好为 3；
- 至少分布在两个段落；
- 至少覆盖两种类型；
- 删除三处毛边后，事实和观点完全不变；
- 三处不会集中在开头、结尾或同一个案例。

最终文章中不加批注、颜色、脚注或其他标记，用户阅读时应把它们视为自然口述毛边。
