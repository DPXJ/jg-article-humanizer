# 三处随机文字毛边规则

## 硬性数量

每篇完成拟人化的文章加入恰好 3 处有意文字毛边。少于三处不交付，多于三处要删除到三处。原文已有自然错别字或重复字时，先判断是否可计入；可计入的毛边不再重复新增。

## 随机选择

从下列四类候选中随机抽取三处，至少覆盖两类，且同一自然段最多一处：

1. **连续重复字或短词，权重 45%**：如「我我」「这个这个」「就就」「再再」。优先模拟口述回填，不重复专名或实义关键词。
2. **常见输入法错别字或近音混用，权重 30%**：只选不改变句子核心意思的轻微错误，如「已经／以经」「时候／时侯」「觉得／觉的」。用户已经确认「一直是我的最佳 CP」写成「一致是我的最佳 CP」属于其有意毛边；只可在这种非事实性的关系表达中沿用，不得把「一直／一致」泛化到时间、数据或结论句。
3. **助词或连接位置的轻微同音混用，权重 15%**：只落在普通叙述中，例如非关键位置的「的／地／得」混用。无法确认不影响理解时，改选前两类。
4. **中英文间距毛边，权重 10%**：允许在普通观点句中偶尔保留「AI的」这类英文词与中文助词粘连。不得用于网址、代码、命令、型号、图片语法、专名内部或任何可能影响复制执行的位置。

随机不等于完全失控。先列出全部安全候选位置，再按权重选择类型和位置；候选不足时，优先使用重复字，不要制造危险错字。

如果用户明确说明某个看似错字或间距问题是故意设定，应把它登记为当篇作者覆盖规则：后续版本不得自动修正，并在位置安全时计入三处总量。它如果位于 Slogan、CTA 或其他通常禁区，只能保留用户已经写下的原样；用户同时确认它就是当篇毛边时，可以计入总量，但模型不得在禁区主动新造。用户没有确认的相似写法，不自动视为作者偏好。

## 绝对禁区

不得主动新增在：

- 标题、导读标题、列表标签和小标题；
- 人名、公司名、产品名、型号、专业术语和功能名；
- 数字、时间、价格、数据、网址和链接文字；
- 正式引语、Slogan、用户确认的最终文案；
- Markdown 图片语法、图注、HTML 标签和属性；
- 免责声明、行动按钮、CTA 和关键结论；
- 任何可能改变事实、立场或操作步骤的位置。

## 内部复核

交付前在内部记录三项：所在段落、原写法、毛边写法。确认：

- 总数恰好为 3；
- 至少分布在两个段落；
- 至少覆盖两种类型；
- 删除三处毛边后，事实和观点完全不变；
- 三处不会集中在开头、结尾或同一个案例。
- 用户确认保留的毛边已经计入总数，没有在其基础上额外再加三处。

最终文章中不加批注、颜色、脚注或其他标记，用户阅读时应把它们视为自然口述毛边。
